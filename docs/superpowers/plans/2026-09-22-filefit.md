# FileFit Implementation Plan

> Use superpowers:subagent-driven-development for bounded engine work and review. User explicitly chose this working directory; no worktree is needed.

**Goal:** Deliver the approved complete image/PDF file compliance application locally.
**Architecture:** React/Vite UI; independent image and PDF adapters; rules validate actual output; browser-local processing and downloadable reports. Native desktop/server processing is not silently substituted.
**Spec:** ../specs/2026-09-22-filefit-full-v1-design.md
**Global constraints:** AGPL-3.0; preserve originals; no upload of user files; failed compliance cannot appear as success; raster PDF mode explicit; passwords not persisted.

## Tasks
- [ ] Image engine: `src/engines/image.ts`, tests for actual image output and impossibility cases. Interface `processImage(file, options, progress, signal):Promise<ProcessResult>` and `inspectImage(file):Promise<FileInfo>`. Reuse codecs; support geometry, DPI and format conversion.
- [ ] PDF engine: `src/engines/pdf.ts`, source attribution; `processPdf(file, options, progress, signal)`, `pdfTool(files, action, options, progress, signal)`. Validate page and text preservation, merge/split, OCR and password paths.
- [ ] Rule engine: `src/core/rules.ts`, `tests/rules.test.ts`: actual size, dimensions, pages, format and naming; reject contradictory rules and malformed values. Run failing tests before implementation.
- [ ] UI: working surface with files, editable constraints, presets, tools, preview, cancellation, output reports, ZIP and local preferences. Build and real-browser integration tests.
- [ ] Distribution: same-origin engines/models, PWA, Docker, README, notices, source provenance, sample files and CI. Verify clean build and real outputs.
- [ ] Final: review engine and workflow tests, move project files to `E:/Newday/FileFit` after processes release file handles; report remaining environment limits honestly.
